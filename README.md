# 👨‍🍳 CheffO3 – ספר המתכונים החכם

אפליקציית מתכונים מלאה בעברית (RTL), מבוססת מסד נתונים, עם סוכן בינה מלאכותית (Claude) שקורא מתכונים מכל מקור ומציג אותם בצורה אחידה.

## מה יש באפליקציה

| יכולת | פירוט |
|---|---|
| 📥 **קליטת מתכונים** | הדבקת טקסט חופשי, הודעת וואטסאפ (כולל ייצוא צ'אט), תיאור קצר ("פסטה עם שמנת לארבעה"), או **צילומי מסך / תמונות** (עד 6). ה-AI מפרק למצרכים (כמות, יחידה, הערה, מחלקה בסופר) ולשלבי הכנה, ומתרגם לעברית כשצריך. |
| 📖 **תצוגה אחידה** | כל מתכון מוצג באותה תבנית: תמונה, זמני הכנה ובישול, רמת קושי, תגיות, **מצרכים בנפרד** (עם תמונת מוצר לכל מצרך) ו**הוראות ממוספרות** עם טיפים וזמנים. |
| 🛒 **תמונות מצרכים** | לכל מצרך השרת מחפש תמונת מוצר ב**שופרסל** ואם לא נמצאה, בוויקיפדיה העברית. התוצאות נשמרות במסד. אפשר להחליף תמונה ידנית (העלאה או קישור), ויש קישור ישיר לחיפוש המוצר בשופרסל. |
| ⚖️ **שינוי כמות מנות** | כל הכמויות מתעדכנות אוטומטית. |
| 🧺 **מה מבשלים ממה שיש?** | מזינים מה יש במקרר ומקבלים את המתכונים השמורים מדורגים לפי אחוז התאמה, עם רשימת מה שחסר. **הצעות השף (AI)** מציעות מתכונים חדשים ממה שיש, ואפשר לשמור אותם. |
| 🛒 **רשימת קניות** | נוצרת ממתכון שלם או רק מהמצרכים החסרים. כמויות זהות מתאחדות, המוצרים מקובצים לפי מחלקות בסופר, ואפשר לסמן מה נאסף. |
| 🟢 **וואטסאפ** | שליחת מתכון או רשימת קניות בוואטסאפ. קליטה מוואטסאפ בהעתק-הדבק, בשיתוף ישיר מוואטסאפ לאפליקציה (PWA באנדרואיד), או דרך **בוט WhatsApp Business** ששומר מתכונים שנשלחים אליו (טקסט או תמונה). |
| 👩‍🍳 **מצב בישול** | מסך מלא, שלב אחר שלב, עם טיימרים. המסך לא נכבה. |
| ✨ **התאמת מתכון** | יצירת גרסה טבעונית, ללא גלוטן, פרווה, מהירה או כל בקשה חופשית, כמתכון חדש. |
| 💬 **שאלו את השף** | צ'אט על המתכון: תחליפים, טכניקות, הקפאה, הגשה. |
| ❤️ **ועוד** | מועדפים, חיפוש לפי שם/מצרך/תגית, קטגוריות, עריכה מלאה, העלאת תמונה, הדפסה, מצב כהה, מותאם לנייד. |

## הרצה

דרישות: Node.js 22.13 ומעלה (המסד הוא SQLite המובנה ב-Node, אין צורך בהתקנות נוספות).

```bash
npm run install:all
```

```bash
cp .env.example .env
```

ממלאים ב-`.env` את `ANTHROPIC_API_KEY` כדי להפעיל את יכולות ה-AI.

```bash
npm run build
```

```bash
npm start
```

האפליקציה עולה בכתובת http://localhost:3001 עם 6 מתכוני דוגמה.

### פיתוח

```bash
npm run dev:server
```

```bash
npm run dev:client
```

ממשק הפיתוח עולה בכתובת http://localhost:5173 ומעביר את בקשות ה-API לשרת.

### גרסת הדגמה (בלי שרת)

```bash
npm --prefix client run build:demo
```

נוצר קובץ אחד, `client/demo.html`, שרץ כולו בדפדפן. הנתונים נשמרים בדפדפן של מי שפותח אותו. בגרסה הזו אין AI ואין תמונות מהסופר.

### בדיקות

```bash
npm test
```

## בלי מפתח API

האפליקציה עובדת גם בלי מפתח: ניהול מתכונים, רשימות קניות, התאמה לפי מצרכים ווואטסאפ זמינים. טקסט מודבק מפוענח בפענוח בסיסי (מזהה "מצרכים:" ו"אופן ההכנה:"). קריאה מתמונות, הצעות, התאמות וצ'אט עם השף דורשים מפתח.

## הגדרת בוט וואטסאפ (אופציונלי)

1. יוצרים אפליקציה ב-[Meta for Developers](https://developers.facebook.com/) ומוסיפים את המוצר **WhatsApp**.
2. ממלאים ב-`.env`: `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_NUMBER_ID`, `WHATSAPP_VERIFY_TOKEN` (מחרוזת שבוחרים), `APP_PUBLIC_URL`, ומומלץ גם `WHATSAPP_ALLOWED_NUMBERS`.
3. בהגדרות ה-Webhook מגדירים את הכתובת `https://<הדומיין שלכם>/api/whatsapp/webhook` עם אותו verify token, ונרשמים לשדה `messages`.
4. שולחים לבוט מתכון (טקסט, הודעה מועברת או צילומי מסך). כמה הודעות ברצף מתאחדות למתכון אחד. הבוט מחזיר קישור למתכון. הפקודה "רשימה" מחזירה את רשימת הקניות.

**שיתוף ישיר מוואטסאפ (אנדרואיד):** פותחים את האפליקציה ב-Chrome (צריך HTTPS) ← "הוספה למסך הבית". אחרי זה CheffO3 מופיע ברשימת השיתוף של וואטסאפ, והטקסט או התמונה נפתחים ישר במסך ההוספה.

## מבנה

```
server/   Express + node:sqlite
  src/db.js         סכמת המסד
  src/recipes.js    מתכונים, חיפוש, התאמה לפי מצרכים
  src/shopping.js   רשימת קניות ומזווה
  src/ai.js         Claude: חילוץ מתכון מטקסט/תמונות, הצעות, התאמות, צ'אט
  src/images.js     תמונות מצרכים (שופרסל ← ויקיפדיה) עם מטמון
  src/whatsapp.js   פורמט הודעות + בוט WhatsApp Cloud API
  src/hebrew.js     עיבוד עברית: פענוח שורות מצרכים, מחלקות, השוואת שמות
client/   React + Vite (RTL)
```

## הערה על תמונות מהסופר

החיפוש בשופרסל משתמש בממשק החיפוש הציבורי של האתר. אם האתר חוסם את הבקשה או משנה את מבנה התשובה, השרת עובר לוויקיפדיה ואחר כך לאימוג'י. אפשר לשנות את הסדר או לכבות ספקים עם `IMAGE_PROVIDERS`, ותמונה ידנית תמיד גוברת. כדאי לבדוק שהשימוש בתמונות תואם את תנאי השימוש של האתרים.
